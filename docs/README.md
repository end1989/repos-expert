# Design notes

`superpowers/` holds the specs and implementation plans written when the tool was first
built (August 2026), kept as a record of how it was designed and why.

They describe **intent at the time, not current behaviour** — the same rule the curator
applies to every repository it reads. Several details have since changed. For how the tool
works now, read [ARCHITECTURE.md](../ARCHITECTURE.md); for what changed and when, read
[CHANGELOG.md](../CHANGELOG.md).
